# Start here

**Begin with [../START_HERE.md](../START_HERE.md)** (complete setup, two-terminal workflow, command reference and troubleshooting).

Then read **[../CHALLENGES.md](../CHALLENGES.md)** (all five missions, rules, three-stage workflow, acceptance criteria and optional hints).

Use [participant_worksheet.md](participant_worksheet.md) to record your observations and [REPORT_TEMPLATE.md](REPORT_TEMPLATE.md) to write up your results.

The coding assistant has project context from `CLAUDE.md` and `AGENTS.md`, but you choose and write all requests. There are **no premade agent prompts** or automated mission commands.
